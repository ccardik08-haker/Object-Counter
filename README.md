# Object Counter

Мобильное Android-приложение для распознавания и подсчёта объектов в
реальном времени с помощью камеры смартфона.

## О проекте

Object Counter анализирует изображение с камеры, обнаруживает объекты и
отображает результат прямо поверх видеопотока. Найденные объекты
выделяются рамками, а приложение показывает их текущее количество.

## Возможности

-   Получение видеопотока с камеры устройства.
-   Распознавание объектов с помощью модели TensorFlow Lite.
-   Отображение обнаруженных объектов с помощью рамок поверх
    изображения.
-   Обновление количества объектов в реальном времени.
-   Локальная обработка на устройстве --- для распознавания не требуется
    постоянное подключение к интернету.

## Технологии

-   **Kotlin** --- язык разработки.
-   **Android Studio** --- среда разработки.
-   **CameraX** --- работа с камерой.
-   **TensorFlow Lite** --- запуск модели обнаружения объектов на
    устройстве.
-   **Compose Canvas / Custom Canvas Overlay** --- визуализация рамок
    обнаружения.

## APK-файл

Готовый APK-файл находится **в корне проекта** и называется:

``` text
app-debug.apk
```

Его можно скачать из репозитория и установить на Android-устройство.
Перед установкой Android может запросить разрешение на установку
приложения из выбранного источника.

## Как работает приложение

1.  Камера получает кадры с помощью CameraX.
2.  TensorFlow Lite анализирует кадры и возвращает найденные объекты, их
    классы и координаты.
3.  Приложение подсчитывает обнаружения.
4.  Canvas Overlay отображает рамки поверх изображения с камеры и
    показывает количество объектов.

## Ограничения

Точность распознавания зависит от освещения, ракурса, качества
изображения и перекрытия объектов. Текущая модель ориентирована на
стандартные классы набора MS COCO; качество обнаружения может
различаться для разных типов предметов.

## Структура проекта

Основные компоненты приложения:

-   `MainActivity.kt` --- интерфейс приложения и разрешения.
-   `ObjectDetectorHelper` --- загрузка модели и выполнение
    распознавания с помощью TensorFlow Lite.
-   `DetectionOverlay.kt` --- отрисовка рамок обнаруженных объектов.
