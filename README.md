# Object Counter 📸📦

**Автоматический счетчик предметов в реальном времени на Android**

Приложение на Kotlin, использующее компьютерное зрение (TensorFlow Lite) для обнаружения объектов через камеру смартфона. Приложение не только считает предметы на экране, но и позволяет сохранять результаты сканирования в локальную галерею, не засоряя память устройства.

## 🚀 Основные возможности

*   **Распознавание в реальном времени**: Использование нейросети EfficientDet-Lite0 для поиска объектов (из 80 классов MS COCO) и отрисовки рамок поверх камеры.
*   **Подсчет объектов**: На экране отображается общее количество найденных объектов и подробный список по классам (например, "Person: 1 шт., Bottle: 2 шт.").
*   **Внутренняя галерея**: Сохранение снимков с наложенными рамками и текстовым описанием в изолированную память приложения. Фотографии не попадают в общую галерею телефона.
*   **Просмотр и удаление**: Возможность открыть сохраненный скан на весь экран и удалить его одним нажатием.
*   **Корректная ориентация**: Решена проблема поворота камеры — сохраненные фото всегда ровные, а рамки точно совпадают с объектами.

## 🛠 Стек технологий

*   **Язык**: Kotlin
*   **UI**: Jetpack Compose
*   **Камера**: CameraX (ImageAnalysis и Preview)
*   **ML**: TensorFlow Lite (Task Vision API)
*   **Модель**: EfficientDet-Lite0 (MS COCO, 80 классов)
*   **Хранилище**: Внутренняя память приложения (`context.filesDir`)
